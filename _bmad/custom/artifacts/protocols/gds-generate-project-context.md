# Project Context Artifact Protocol

Use `_bmad-output/planning-artifacts/architecture.md` as the sole target-architecture source and `_bmad-output/project-context.md` as the sole output. The source library's `TECHNICAL_ARCHITECTURE.md` is prototype-baseline evidence only. Stamp the canonical architecture path and SHA-256 revision into project-context frontmatter, preserve lean implementation rules, and reject duplicate project-context files.
