- (decision by user) Research online current tools and resources for a solo/non-artist 3D Godot pipeline, prioritizing model generation, mesh cleanup, rigging, animation, import interoperability, usable asset libraries, licensing, cost, and first-vertical-slice fit.
- (source) Primary sources checked 2026-08-30: Tripo CLI, v3.1 generation, v2.5 rig and animation families, pricing, and terms. Key result: explicit current support for quadruped, hexapod, octopod, serpentine, aquatic, and avian rig types.
- (source) Primary sources checked 2026-08-30: Meshy API and web changelogs, Meshy-7, Smart Topology, Text-to-Motion, rigging and animation docs, pricing, terms, and Godot plug-in. Key result: useful humanoid convenience, but API docs reject quadrupeds while web docs advertise quadruped auto-rigging.
- (source) Primary sources checked 2026-08-30: Rodin Gen-2.5 API, Godot add-on, terms, and API retention policy. Key result: strong static prop/environment iteration and Godot bridge; API retention policy is narrower than broader service terms.
- (source) Primary sources checked 2026-08-30: Godot 4.7 import docs, Blender 4.5 LTS, Blender cleanup/baking, AutoRemesher, Blender bridge, and MeshLab. Key result: use GLB as runtime hand-off and Blender as canonical cleanup/export DCC.
- (source) Primary sources checked 2026-08-30: Rokoko Create and pricing, Cascadeur plans, AccuRIG, and DeepMotion pricing. Key result: Rokoko for humanoid motion, Cascadeur for high-impact grapple/combat polish, and no general humanoid tool should be assumed to solve custom creatures.
- (source) Primary sources checked 2026-08-30: Quaternius, KayKit, Poly Haven, ambientCG, and Fab licensing/resource pages. Key result: use CC0 libraries for slice scaffolding and style tests; use Fab listing by listing for paid hero assets.
- (source) Primary sources checked 2026-08-30: ArmorPaint, Material Maker, Effekseer, Sonniss GDC 2026 bundle/license, Terrain3D, ProtonScatter, and Scatter for Godot. Key result: local style, VFX, audio, terrain, and scatter support can reduce artist dependence but gameplay-critical geometry remains explicitly authored.
- (source) Primary sources checked 2026-08-30: Microsoft TRELLIS.2, Stability Stable Fast 3D and model card, and VAST TripoSR. Key result: TRELLIS.2 is not a local fit for AMD RX 6800; Stable Fast 3D/TripoSR are static-prop experiments, with license constraints for Stable Fast 3D.
